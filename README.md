## 🎯 Objective

To analyze weather data and identify patterns over time, helping understand how environmental conditions can impact safety and planning.

---

## 🛠️ Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn

---

## 📊 Dataset

The dataset contains daily weather data for Seattle (2016), including:

* Date
* Maximum Temperature
* Mean Temperature
* Minimum Temperature

Source: Plotly Public Dataset

---

## 📊 Project Overview

This project focuses on **time-series analysis** of weather data to uncover seasonal trends and variations.

Key tasks performed:

* Data loading and cleaning
* Feature engineering (Month, Day extraction)
* Exploratory Data Analysis (EDA)
* Visualization of trends and distributions

---

## ⚙️ Workflow

1. Loaded dataset from source
2. Checked data types and missing values
3. Converted Date column to datetime
4. Created Month and Day features
5. Visualized data using graphs
6. Interpreted patterns and trends
